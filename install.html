Installing Exowright Preview on a Mac

Exowright Preview is an early, unfinished version of Exowright, provided for testing with known limitations: expect bugs, missing features and balance changes. It needs macOS 13 or later. The app is built for Apple silicon and Intel Macs but has so far been tested on Apple silicon only. The download is public: anyone with the link can get it.

Why macOS warns you

Apple checks apps from the internet in two ways: a Developer ID signature from a paid Apple developer account, and notarization, an automated Apple malware scan. Exowright Preview has neither. It is signed only locally, so macOS can tell whether the app was changed but cannot tell who made it. The first time you open it, macOS says it could not verify that the app is free of malware.

That is expected. It does not mean Exowright Preview is harmful, but it does mean you are trusting where you downloaded it from. Only continue if all of these are true:

  • you downloaded the disk image from the official Exowright Preview page, and
  • its checksum matches the one published there (step 2), and
  • you trust the person who sent you the link.

Steps

  1. Download the disk image, Exowright-Preview-<version>-<build>.dmg, from the Exowright Preview page.
  2. Check the checksum. Open Terminal (Applications → Utilities), type shasum -a 256 (with a space at the end), drag the downloaded file into the Terminal window and press Return. The long code it prints must exactly match the SHA-256 shown next to the download on the Exowright Preview page. If it does not match, delete the file and do not open it.
  3. Install. Double-click the disk image and drag Exowright Preview onto the Applications folder.
  4. Open it from Applications (double-click). macOS shows a warning. Click Done. Do not move it to the Trash.
  5. Allow it once. Open System Settings → Privacy & Security and scroll down to Security. Next to the message about Exowright Preview, click Open Anyway. Then confirm with Open Anyway again and enter your Mac login password or use Touch ID. The button appears only for about an hour after step 4; if it is gone, repeat step 4.
  6. Check that it works. Exowright Preview opens. Choose New Colony and build something. Open the menu (☰, top right) and choose Save (or press F5). Quit and reopen the app, then choose Continue Colony. Your colony should be there.

You only need to do steps 4 and 5 once. Your colonies are stored in ~/Library/Application Support/Exowright Preview, separate from any other Exowright version. Deleting the app does not delete them.

Updates

Open the menu (☰, top right) in the game and choose Check for Updates. Exowright Preview downloads the update, checks its Exowright update signature (an update that is damaged or not signed by Exowright is refused), installs it and reopens. Your colonies stay where they are. If macOS asks you to approve the app again after an update, repeat step 5.

Please do not

  • turn off Gatekeeper, System Integrity Protection or any other macOS security setting. None of that is needed.
  • install a copy that someone sent you directly, or one whose checksum does not match.

If it does not install

Macs managed by a school, an employer or another organization may block apps that are not notarized. In that case Exowright Preview cannot be installed on that Mac. Ask its administrator, and do not try to work around the restriction.
