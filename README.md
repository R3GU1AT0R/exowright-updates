# Exowright updates

Downloads and the update feed for **Exowright Preview**, served by GitHub Pages at https://r3gu1at0r.github.io/exowright-updates/.

This repository holds no source code. Disk images and update archives are assets of the `preview-archives` release. Every update archive is signed with Exowright's EdDSA update key and verified by the game before it installs. The preview is not notarized by Apple (see install.html).

Everything here is public.
