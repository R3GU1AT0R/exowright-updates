Release notes

Not notarized by Apple. This preview is not signed with an Apple Developer ID and not notarized, so macOS asks you to approve it once (System Settings → Privacy & Security → Open Anyway). Check the SHA-256 before opening it. Never turn off Gatekeeper or other macOS security settings.

How to install, step by step

Early preview. Exowright is unfinished and provided for testing, with known limitations: expect bugs, missing features and balance changes. Your colonies are saved in ~/Library/Application Support/Exowright Preview and are kept when the game updates.

These files are public: anyone with this address can download them. Updates are delivered inside the game (menu → Check for Updates); every update archive is verified with Exowright's EdDSA update signature before it is installed.
